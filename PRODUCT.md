# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React + Vite + TypeScript (указано пользователем: «Стек React. White» — «White» трактуется как Vite). Запуск внутри Telegram как Mini App (telegram-web-app.js). На этом этапе — только вёрстка на моках, без бэкенда.

Бэкенд (решено пользователем 2026-10-07):
- API — Python + FastAPI;
- база данных — PostgreSQL;
- Redis — обязателен.

## Users

Русскоязычные люди, живущие за рубежом (экспаты и долгосрочные путешественники): Бали, Пхукет, Бангкок, Дубай, Тбилиси и т.п. Ищут и предлагают аренду жилья и байков, услуги, вещи, работу рядом с собой — сейчас делают это через хаотичные Telegram-чаты-барахолки.

## Product Purpose

Classify — доска объявлений внутри Telegram. Позволяет быстро найти объявление в своём городе/районе и связаться с автором, а также за пару минут подать своё. Успех — пользователь находит нужное в своём районе без пролистывания сотен сообщений в чатах.

## Positioning

Локальность на первом месте: город и район — главный фильтр и главный контекст каждого объявления (подтверждено пользователем как ключевое отличие от чатов-барахолок и Авито).

## Operating Context

Открывается из Telegram-бота как Mini App на телефоне; связь с продавцом — переход в личный чат Telegram. Валюты разные в зависимости от страны.

**Правило валюты (решено пользователем 2026-10-08):** у каждой страны своя валюта. Цена объявления пишется в валюте той страны, где оно опубликовано: Индонезия (Бали) — рупии IDR, Таиланд (Пхукет, Бангкок) — баты THB, ОАЭ (Дубай) — дирхамы AED, Грузия (Тбилиси) — лари GEL. Валюту продавец не выбирает — она определяется городом объявления.

## Capabilities and Constraints

- Сейчас: только UI на мок-данных, без API, авторизации, оплаты и модерации.
- Экраны: лента, поиск с фильтрами, карточка объявления, подача объявления, избранное, мои объявления, профиль продавца с отзывами.
- Место при первом запуске определяется по IP (только город); не определили — человек выбирает страну и город. Ручной выбор главнее автоматического.
- KYC (проверка личности): отметка «Личность подтверждена» только у прошедших; провайдер — Didit (решено пользователем 2026-10-08). При отказе ничего не показываем — человек просто остаётся непроверенным. KYC добровольный: не обязателен ни для каких категорий и платных услуг.
- Язык: на старте только русский, выбора языка в настройках нет (решение пользователя 2026-10-09). Другие языки — позже, не решено.
- Не решено (не выдумывать): монетизация, модерация, другие языки интерфейса, хранилище фото, правила по запрещённым категориям.

## Brand Commitments

Только тёмная тема Fragment (решение пользователя 2026-10-09; раннее требование «светлый интерфейс» отменено, светлой темы нет). Логотипа, фирменного цвета и шрифта нет.

## Evidence on Hand

Реальных объявлений, пользователей, отзывов и статистики нет — всё в `src/mocks` вымышлено и помечено как моки. Нельзя выдавать моки за реальные данные или метрики.

## Product Principles

1. Сначала «где» — город и район видны и меняются в один тап везде.
2. Связаться — один тап: всё ведёт в чат Telegram с продавцом.
3. Подать объявление быстрее, чем написать пост в чат.
4. Ощущаться родным для Telegram: нативные кнопки, haptics, тема.
