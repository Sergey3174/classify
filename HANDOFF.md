# HANDOFF — Classify (Telegram Mini App)

Контекст для новой сессии. Проект вынесен из сессии, где параллельно настраивался Notion/OpenClaw — к этому проекту она отношения не имеет.

## Цель

Доска объявлений Classify как Telegram Mini App для русскоязычных, живущих за рубежом (Бали, Пхукет, Бангкок, Дубай, Тбилиси). Главная идея — **локальность**: город и район — главный фильтр, у каждого объявления видно расстояние. Сейчас этап — **только вёрстка на моках**, без бэкенда.

Стек: React 19 + Vite + TypeScript, react-router-dom 7, lucide-react. Запуск: `npm run dev` (порт 5173), сборка `npm run build`. Конфиг превью для приложения: `.claude/launch.json` (имя `classify`).

## Что сделано

- Продуктовая правда — `PRODUCT.md` (аудитория, позиционирование, принципы).
- Экраны (`src/pages`): Главная (`Home`), Поиск с фильтрами (`Search`), Карточка объявления (`Listing`), Подача — мастер из 5 шагов (`Create`), Избранное / Мои объявления / Профиль продавца / Мой профиль (`Collections`).
- Компоненты (`src/components`): карточка и строка объявления, шторки (выбор места страна→город→район с поиском, фильтры), нижняя панель `TabBar` (Главная · Подать · Избранное · Мои), имитация шапки и MainButton Telegram для обычного браузера.
- Интеграция Telegram (`src/telegram`): `ready/expand`, нативные BackButton и MainButton, haptics, открытие чата с продавцом, цвета шапки.
- Мок-API с задержкой (`src/api/index.ts`) — сигнатуры готовы под замену на `fetch`. Моки в `src/mocks` (фото — Unsplash, люди и объявления вымышлены).
- Состояние (`src/store/app.tsx`): избранное, выбранное место, тосты (localStorage).

## Автоопределение места — сделано во фронте 2026-10-09 (на моке)

Решение пользователя: **определяем по IP; если не определили — показываем выбор страны и города.**

- Первый запуск (место не сохранено): `AppProvider` показывает `FirstLocation` (`src/pages/FirstLocation.tsx`) вместо приложения — «Определяем город…» → `api.detectLocation()`.
  - Город определён → сразу лента этого города, район — «весь город» (по IP района не узнать), `source: 'auto'`; в шапке главной «Страна · определено автоматически».
  - Не определён → экран «Где вы?»: страны и города из справочника; выбор — `source: 'manual'`.
- Ручной выбор главнее: автоопределение само его не перезаписывает. В шторке места — «Определить автоматически» (успех → тост «Определили: …», неудача → тост «выберите город вручную», шторка остаётся).
- Мок `detectLocation` (`src/api/index.ts`): по умолчанию Бали; для проверки — `?geo=fail` (не определили) или `?geo=<cityId>`.
- **Бэкенд (следующий этап):** `GET /geo` — город по IP запроса через GeoIP-базу; вернуть город из нашего справочника или `null`, если IP неизвестен или город не обслуживаем. Координаты и IP не хранить. Какую GeoIP-базу брать — не решено.
- Расстояния «600 м от вас» по-прежнему вымышленные: по IP точных координат нет.

## Проверить: суммы в рупиях в фильтре цены (замечание 2026-10-08)

Пользователь заметил, что, возможно, ошибка в фильтре цены: 20 000 000 Rp (значение, которым проверялся фильтр на Бали) показалось слишком маленькой суммой. Для справки: 20 млн Rp ≈ 1 200–1 300 USD — для Бали это средняя сумма, но с рупиями легко ошибиться на порядок. Что проверить в следующей итерации:
- Масштаб цен в моках Бали (`src/mocks/listings.ts`, переведены из USD по ~16 400 Rp за $): вилла 29 млн Rp/мес, KTM 118 млн Rp, MacBook 15,5 млн Rp — сверить с реальными ценами рынка, поправить, если неправдоподобно.

Варианты: группировка разрядов при вводе, подсказка «= 20 млн Rp» под полем, ввод в «млн» для IDR, быстрые диапазоны («до 5 млн», «до 20 млн», «до 50 млн»). Не решено — показать пользователю варианты.
- Убедиться, что фильтр сравнивает именно в рупиях (сейчас так: без пересчёта, `l.price <= priceTo`) и что «тыс / млн Rp» в карточках и в поле фильтра не путают человека.
